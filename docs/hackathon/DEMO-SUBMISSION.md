# Demo And Submission

## Demo Goal
Use the 2 minutes to show the agent acting on a real problem, not to explain architecture. Keep proof visible: ClawUp/Telegram behavior, ERC-8004 listing, and x402 payment evidence if the idea uses payments.

## Two-Minute Structure
| Time | Segment | Evidence |
|---:|---|---|
| 0:00-0:15 | Name the user and problem | One sentence problem statement |
| 0:15-0:35 | Ask the agent what it does | Self-disclosure and usage instructions |
| 0:35-1:20 | Run the core workflow | Agent takes meaningful action |
| 1:20-1:40 | Show trust and guardrails | Confirmation before risky action |
| 1:40-1:55 | Show GOAT proof | ERC-8004 listing on `8004scan` |
| 1:55-2:00 | State continuation plan | Clear next step after hackathon |

## Judge Tests To Prepare
- Ask the agent: "What do you do?"
- Ask the agent how to use it.
- Trigger the main workflow from Telegram.
- Attempt a high-risk action, such as spending maximum funds or changing configuration.
- If x402 is included, trigger a payment or transaction and show verification.
- Show the ERC-8004 mainnet listing.

## Submission Checklist
- Agent built through ClawUp.
- Telegram path works.
- Agent registered on GOAT Network Mainnet with ERC-8004.
- Agent visible on `https://8004scan.io/agents?chain=2345`.
- Final submission form complete: https://bit.ly/openclaw-hackathon-submission
- Demo script filled from `docs/templates/demo-script.md`.
- Public links and proof artifacts ready.

## Evidence To Capture
- Agent name.
- Telegram bot username.
- ClawUp agent name or ID if available.
- ERC-8004 agent ID.
- GOAT Mainnet transaction hash for registration.
- 8004scan URL.
- x402 order or settlement proof if used.
- Short continuation plan.
